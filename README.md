🌙✨ Eid Greeting Generator

A fun and interactive Eid Greeting Generator built using HTML, CSS, and JavaScript. Users can enter their name and instantly receive a personalized Eid Mubarak wish, creating a unique and festive experience.

✨ Features
Personalized Eid Mubarak messages
User name input functionality
Dynamic content generation with JavaScript
Attractive and festive design
Responsive layout for different devices
Simple and user-friendly interface

🚀 Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)


📚 What I Learned
Handling user input with JavaScript
DOM manipulation
Dynamic text generation
Form interaction and event handling
Creating interactive web experiences

This project was created to celebrate Eid in a creative way while practicing front-end web development skills and JavaScript fundamentals.

⭐ Feel free to try it out and share your personalized Eid wishes! 🌙🎉✨
